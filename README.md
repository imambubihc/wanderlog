# Wanderlog 🌍

A simple travel journal website created as part of the CodGen Frontend Internship – Week 1.

## 📌 Project Description

Wanderlog is a beginner-friendly travel journal homepage designed to help travelers discover beautiful destinations and record their travel experiences.

This Week 1 project focuses on frontend fundamentals such as semantic HTML, CSS styling, Flexbox, and basic responsive design.

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript (Basic)

## ✨ Features

- Responsive navigation bar
- Wanderlog logo/wordmark
- Home, Destinations, and About navigation links
- Hero section
- Travel-related headline and description
- "Start Your Journey" call-to-action button
- About Wanderlog section
- Responsive layout for mobile screens
- Basic JavaScript button interaction
